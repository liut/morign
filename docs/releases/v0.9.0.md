# v0.9.0 — Skills、记忆分层与语料导入

2026-09-10 · 完整变更见 [CHANGELOG.md](../../CHANGELOG.md)

## 新增

- **Agent Skills**：SKILL.md 与资源文件按技能存库，系统提示只注入元数据，全文按需加载（`skill_list` / `skill_read` / `skill_file_list` / `skill_file_read` 工具、`/skill` 指令），技能可见性按频道控制；提供用户级 `/api/skills` 与 keeper 专属 `/api/admin/skills`
- **记忆分层衰减**：写入时按重要性自动分层（working / short-term / long-term），召回时按遗忘曲线重排并强化，支持 tier 过滤与阈值配置
- **语料导入 API**：`POST /api/corpus/imports` 异步导入 CSV，可查进度与失败明细；新增 `/api/corpus/documents` 文档增删改查，写操作限 keeper
- `/api/session` 返回 `keeper` 字段

## 修复

- 记忆强化未落库、`Tier` 默认值导致建表失败、`memory_forget` 残留向量
- 飞书 WebSocket `Start` 错误判断失效

## 升级

- 启动时自动执行 schema 初始化与 migration，无需手工操作
- 依赖升级 `cupogo/andvari`

新增环境变量（均有默认值）：`MEMORY_*`、`SKILL_*`
